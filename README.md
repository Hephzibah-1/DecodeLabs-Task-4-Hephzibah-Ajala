# Data Analytics Internship at DecodeLabs — Project 4: Data Visualization

## Project Overview

This project focuses on using Microsoft Power BI to visualize, analyze, and communicate business insights from a retail orders dataset. It was completed as part of the DecodeLabs Data Analytics Industrial Training Program, building on the cleaned dataset prepared during Project 3.

## Objectives

- Transform the cleaned retail dataset into meaningful visualizations.
- Analyze monthly recorded sales trends.
- Compare product performance based on recorded sales.
- Examine order distribution across different statuses.
- Analyze recorded sales by referral source.
- Compare average order value across payment methods.
- Develop business insights and recommendations from the dashboard.
- Present findings through an interactive Power BI dashboard.

## Tools Used

- Microsoft Power BI
- Cleaned retail orders dataset from Project 3

## Dataset Overview

The dataset contains **1,200 records and 14 columns**, covering retail orders from January 1, 2023, to June 30, 2025.

The cleaned dataset from Project 3 was used as the starting point for this project. Data cleaning was not repeated; the focus was on visualization, analysis, and communicating findings.

Key fields include OrderID, Date, CustomerID, Product, Quantity, UnitPrice, PaymentMethod, OrderStatus, CouponCode, ReferralSource, and TotalPrice.

## Project Workflow

### 1. Dataset Preparation
- Imported the cleaned retail orders dataset from Project 3 into Power BI.
- Reviewed the available fields and identified those needed for the analysis.
- Used the prepared dataset as the basis for the dashboard.

### 2. KPI Development
- Created key performance indicators to summarize total orders, customers, recorded sales, and average order value.
- Used the KPI cards to provide a quick overview of retail performance.

### 3. Data Visualization
- Created a line chart to analyze monthly recorded sales trends.
- Used a bar chart to compare recorded sales across products.
- Visualized order counts across different order statuses.
- Compared recorded sales across referral sources.
- Analyzed average order value by payment method.

### 4. Interactive Dashboard Development
- Designed a dashboard with a consistent color palette and clear visual hierarchy.
- Added year and order status slicers to allow users to filter the report.
- Organized the visualizations, KPIs, and key findings into a single dashboard.

### 5. Insights and Recommendations
- Identified products with the highest and lowest recorded sales.
- Examined monthly sales performance and differences across referral sources.
- Highlighted the proportion of cancelled and returned orders.
- Developed business recommendations based on the observed patterns.
- Reviewed the dashboard for readability, consistency, and appropriate interpretation of the results.

## Key Findings

- **Chair** recorded the highest product sales at 195,620.11, narrowly ahead of Printer at 195,612.61.
- **Phone** recorded the lowest product sales at 151,722.39.
- **June 2024** had the highest monthly recorded sales at 68,068.54, while April 2023 had the lowest at 27,751.71.
- **Cancelled and returned orders** accounted for 497 orders, representing approximately 41.4% of the 1,200 recorded orders.
- **Instagram** recorded the highest total sales among referral sources at 275,285.45, while Referral recorded the lowest at 226,815.58.

## Dashboard Features

- KPI cards for total orders, customers, recorded sales, and average order value.
- Monthly recorded sales trend visualization.
- Recorded sales comparison by product.
- Order count comparison by status.
- Recorded sales comparison by referral source.
- Average order value comparison by payment method.
- Interactive year and order status slicers.
- Key insights and business recommendations.
